# SEARCH AUTOCOMPLETE ENGINE

A full-stack search autocomplete engine built with Node.js backend and React frontend.

## Features
- Real-time autocomplete suggestions using Trie data structure
- Fast and efficient search algorithm
- RESTful API backend
- Modern React frontend with Vite

## Project Structure
```
autocomplete-search-engine/
├── backend/       - Node.js server
├── frontend/      - React application
└── docs/          - Documentation
```

## Getting Started

### Backend Setup
```bash
cd backend
npm install
npm start
```

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

## Technologies
- **Backend**: Node.js, Express
- **Frontend**: React, Vite
- **Data Structure**: Trie for efficient autocomplete
